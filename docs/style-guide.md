# Style guide

Tento dokument definuje vizuálny smer webu. Používaj ho ako spoločnú referenciu pri návrhu stránok a jednotlivých komponentov.

## Farebná paleta

| Použitie | Farba | Ukážka |
| --- | --- | --- |
| Akcentová modrá, hlavne pre CTA tlačidlá a odkazy | `#2563EB` | Modré tlačidlo s bielym textom |
| Texty a nadpisy | `#0F172A` | Tmavosivý text s dobrým kontrastom |
| Svetlé pozadie kariet | `#F8FAFC` | Jemné, neutrálne pozadie |

Farby používaj konzistentne a s dostatočným kontrastom. Modrú vyhraď najmä pre prvky, ktoré majú upútať pozornosť alebo vyzvať k akcii.

## Typografia

Použi čisté bezpätkové písmo **Inter** alebo **Roboto**. Nadpisy majú byť výrazné a ľahko skenovateľné, bežný text pohodlne čitateľný. Zachovaj jasnú hierarchiu veľkostí a váh písma.

## Tlačidlá

- CTA tlačidlá majú akcentové modré pozadie `#2563EB` a biely text.
- Rohy zaobli v rozsahu **6 až 8 px**.
- Text tlačidla má byť stručný, jasný a dobre čitateľný.
- Vedľajšie tlačidlá môžu byť vizuálne pokojnejšie, no majú zostať zreteľné a ľahko použiteľné.

## Celkový vizuálny dojem

Web má pôsobiť **čisto, remeselne a moderne**. Uprednostni prehľadné rozloženie, vzdušné rozostupy, jednoduché tvary a dôsledné zarovnanie. Detaily majú podporovať obsah a použiteľnosť, nie zbytočne súperiť o pozornosť.
